JustTheHelper Guild Pass — after purchase
==========================================

1. In Discord (server with JustTheHelper), run: /subscribe info
   Copy your server link code: JTH-XXXXXX

   You should have pasted this code in the Ko-fi checkout MESSAGE field.
   If you did not, contact support with your Ko-fi receipt.

2. Run: /subscribe status
   Tickets should unlock within about a minute.

3. Run: /tickets setup  (parent channel + staff role)
4. Run: /tickets panel  (where members open tickets)

Renewal: buy the guild pass again before ~31 days expire.

More help: https://justthebuilder.fly.dev/kofi/helper-thanks
